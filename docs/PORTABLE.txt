Stride 1.0.0 for Windows x64 — release candidate until publication is approved

Extract the ZIP and open stride.exe. Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required. No Node.js, terminal, or local server is needed. If WebView2 is missing, use the installer from the same approved GitHub Release; its initial runtime download requires internet.

Portable describes the application files. Study data stays in your Windows user profile, normally under %LOCALAPPDATA%\com.philippaglinawan.stride, shared with the ordinary installed edition. Copying the executable does not copy your history.

An email/password account is required. Create an account, confirm its email, then sign in. First sign-in or expired credentials need internet. A saved eligible session can restore its local workspace offline. Study actions save locally and queue until reconnect. Subjects, completed sessions, recorded study days, and shared study preferences synchronize to devices signed into the same account.

Active timers, appearance, notifications, and recovery copies remain device-local. Notifications require Stride to be open. Signing out hides the workspace and keeps its local history and pending changes. Sign back into the same account to reopen it.

Settings > Export JSON saves a readable backup. Keep backups outside the app profile. Import JSON reviews the file, requires a fresh backup download, reconciles cloud history, and adds records without replacing unrelated history. Different versions require review; identical records are deduplicated. Imported timers restore paused. Existing anonymous history is offered for explicit import after sign-in and its source remains stored.

Settings > Cloud synchronization and Recovery and sync issues show pending changes, conflicts, and preserved copies. Wait for sync to finish before moving devices. Clearing the profile can lose unsynced changes, timers, and recovery copies. Synced completed history can download after signing in again. Normal installer uninstall preserves data by default; selecting Delete app data removes local storage. Deleting this extracted ZIP folder leaves profile data in place.

Builds are unsigned. Verify downloads against SHA256SUMS.txt from the same release.
